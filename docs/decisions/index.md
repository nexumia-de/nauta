# Decisions

* [App name Nauta](app-name.md) - Latin for sailor, a nod to Navidrome without its name.
* [AGPL-3.0 licence](license.md) - Like Cirro and Ephyra.
* [Credentials in form bodies](form-post-credentials.md) - Token authentication in POST bodies, password in the keyring, local address only on listed home networks.
* [New music through MeTube](metube-downloads.md) - Search and downloads run in the user's own MeTube, searched through its /browse; the phone never talks to YouTube.
